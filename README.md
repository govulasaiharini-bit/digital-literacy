##  Project Overview
This project was completed as part of the **CSE0001 – Digital Literacy** course.  
As a Student Digital Ambassador, the goal of this project is to help students understand and use digital tools effectively, communicate professionally, and stay safe online.

The project consists of five tasks that cover different aspects of digital literacy, including infographic creation, building a digital portfolio, exploring platforms, email etiquette, and cybercrime awareness.
